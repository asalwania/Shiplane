# UI source: a pasted reference image

1. Copy the image faithfully — layout, spacing, hierarchy, color. Don't add flourishes the image doesn't show.
2. Where the image is ambiguous (a state it doesn't depict, a breakpoint it doesn't show), fall back to the project's existing `design.md` if one exists, or make the smallest reasonable extension consistent with what the image does show.
3. If no `design.md` exists yet, derive one from the image (accent color, greys, type scale) so later screens stay consistent with this one, rather than eyeballing each new screen against the original image again.
4. Continue to [implementation.md](implementation.md).
