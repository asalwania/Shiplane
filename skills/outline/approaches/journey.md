# Delivery approach: one whole journey at a time

Finish one complete user path fully — every state it can be in — before starting the next.

Good when each path must feel finished before users see it: no half-built flow sitting next to a polished one.

Recorded in the scope file; the build order groups every item belonging to one journey together and marks the whole journey `done` only once every item in it is, rather than letting items from different journeys interleave.
